# 漫画爬虫与下载器

一个强大的 OOMOL 工作流包，可以自动从网页下载漫画图片并将其转换为数字漫画书。

## 这个包能做什么？

这个包帮助您将任何漫画网页转换为可下载的数字漫画书。只需提供漫画网页 URL，该包将：

1. **从网页提取漫画图片**
2. **自动下载所有图片**
3. **创建数字漫画书**，支持您偏好的格式（EPUB、CBZ 或 PDF）

## 适合谁使用？

- **漫画爱好者**，想要离线阅读漫画
- **数字图书馆建设者**，收集漫画
- **任何人**，想要在本地保存基于网络的漫画

## 主要功能

### 🌐 网络漫画提取
- 分析任何漫画网页并智能识别漫画图片
- 自动处理各种漫画网站格式
- 按正确的阅读顺序排序页面

### 📥 自动下载
- 从网页下载所有漫画图片
- 为漫画书创建正确组织文件
- 处理不同的图片格式和大小

### 📚 数字图书创建
- 将下载的图片转换为数字漫画格式：
  - **EPUB**：适用于 Kindle、Kobo 等电子阅读器
  - **CBZ**：标准漫画书存档格式
  - **PDF**：适用于任何设备的通用格式

### 🎨 智能处理
- 自动生成适当的文件名
- 保持正确的页面阅读顺序
- 筛选和处理仅图片文件

## 工作原理

### 简单的 3 步流程

1. **输入**：提供漫画网页的 URL
2. **处理**：工作流自动：
   - 爬取网页内容
   - 使用 AI 识别漫画图片
   - 按顺序下载所有图片
   - 创建数字漫画书
3. **输出**：获取准备好阅读的漫画书文件

### 技术组件

该包包含两个主要工作流组件：

#### 下载图片块
- **用途**：下载单个漫画图片
- **输入**：图片 URL 和保存目录
- **输出**：下载的图片文件路径
- **使用场景**：非常适合批量下载漫画图片

#### 漫画爬虫工作流
- **用途**：完整的漫画提取和图书创建
- **输入**：漫画网页 URL 和保存位置
- **输出**：数字漫画书文件（EPUB/CBZ/PDF）
- **功能**：
  - AI 驱动的内容分析
  - 自动图片提取
  - 图书格式化和创建

## 入门指南

### 要求
- 已安装 OOMOL 平台
- 用于下载的互联网连接
- 漫画文件的存储空间

### 使用方法
1. 在 OOMOL 中打开漫画爬虫工作流
2. 输入漫画网页 URL
3. 选择您的保存目录
4. 选择输出格式（EPUB、CBZ 或 PDF）
5. 运行工作流
6. 在指定目录中找到您的数字漫画书
